# Auto-rediscover a TV by MAC when its saved IP fails to connect


Source: SSDP/Wi-Fi resolver push review (2026-11-04).

When connecting fails, try the saved IP, else run SSDP and match the TV by MAC (as tv-tuneup src/discovery/resolve.mjs does), then update the saved IP in the inventory. Inventory already merges IP drift by MAC on discovery; this adds the automatic trigger on connect failure.

Acceptance: a TV whose DHCP address changed reconnects without manual rediscovery; covered by a JVM test with a fake discovery and probe.
