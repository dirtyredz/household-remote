# Show 'Phone not on Wi-Fi' instead of Offline

Owner phone test 2026-10-28 on v0.2.0: the phone was on 5G with Wi-Fi off, and the app only showed 'Offline' / 'Turn on · Off or unreachable', with no hint why. When there is no active Wi-Fi network (ConnectivityManager NetworkCapabilities TRANSPORT_WIFI), the status should read 'Phone not on Wi-Fi', offer a button that opens Wi-Fi settings, and suppress reconnect attempts until Wi-Fi returns, resuming recovery when it does. Power 'Turn on' should show the same hint. Target v0.2.1. Also re-test dk-46864487 (SSDP), since that test may have been on mobile data.
