# SSDP socket: fail fast when no Wi-Fi instead of unpinned fallback


SsdpSocket.kt: when phoneWifiNetwork() returns null, AndroidSsdpSocket falls back to an unpinned socket, while WakeOnLan fails fast with "Connect to Wi-Fi first". The 2026-10-26 discovery ADR rejects the unbound socket because it reproduces "no TVs found". Make AndroidSsdpSocket throw when there is no Wi-Fi so discover() reports it like WOL (or record the fallback as deliberate in the ADR). From the v0.2.9 push sign-off.
