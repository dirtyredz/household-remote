# Features

| Capability | v1 implementation | Physical acceptance |
|---|---|---|
| Compose remote / owner shell | Distinct application IDs, same remote UI | Pending phone |
| Discovery / manual IP / JSON import | Bounded SSDP and REST; MAC identity; remembered selection | Pending household LAN |
| Pair / reconnect | Exact TV Tuneup name, 90-second approval, encrypted per-phone token, TV certificate pin | Pending two phones / both TVs |
| Remote | Navigation, home, source, volume, mute, channels, single standby | Pending models / latency |
| Wake | Three magic packets on active Wi-Fi interface, bounded readiness probes | Pending standby settings |
| Calibrated shortcuts | Netflix, Prime, Disney+, Plex; per-TV local sequences, exclusive/cancellable | Disabled until owner calibrates |
| Distribution | Unsigned CI, local attended signer, public release updates | Pending real key / publication / phone |
| Parent controls | Absent from both flavors | v2 only |
